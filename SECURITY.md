# Security policy

## Reporting a vulnerability

Please do not publish exploitable details in a public issue. Send a report to
the project maintainer through the contact listed on the website or GitHub,
including the affected version, reproduction steps, impact, and a minimal
proof of concept when safe.

Supported releases are the latest published launcher release and the current
`main` branch. Reports involving tokens, update downloads, archive imports,
or installer execution are treated as high priority.
