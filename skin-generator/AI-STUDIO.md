# Google AI Studio

Самостоятельный локальный генератор Minecraft Classic (4px arms). Описание и шаблон отправляются Nano Banana 2. Тот же PNG 64×64 отображается в skinview3d и скачивается.

## Запуск

Требуется Node.js 22.12+.

```powershell
cd skin-generator
npm install
npm run dev
```

Заполните `GEMINI_API_KEY=` в `.env` этой папки. Если файла нет, скопируйте `.env.example` в `.env`. Не добавляйте ключ в VITE-переменные: они доступны браузеру. `.env` исключён из Git.

«Проверить подключение» подтверждает наличие ключа на сервере, но не его действительность или квоту. Файл перечитывается при каждом API-запросе; перезапуск не нужен. Первый запрос генерации проверит доступ к Google и может расходовать платную квоту. Автоматических повторов платных запросов нет.

По умолчанию `GEMINI_MODEL=gemini-3.1-flash-image`. Если модель недоступна, укажите актуальный ID из AI Studio. API: `v1/models/{model}:generateContent`; ключ передаётся заголовком только с сервера.

## Проверки

```powershell
node --test server/api.test.mjs
npm run build
npm run preview
```

API встроен в локальный Vite-сервер, работает в dev и preview. Публикация dist на статическом хостинге не включает API. Сервис привязан к 127.0.0.1 и предназначен для одного локального пользователя; публичный хостинг потребует отдельного защищённого backend.

## Ограничения

- Только основной слой Classic. Внешние слои и Slim пока не поддерживаются.
- Проверяются квадратное изображение, конечный размер, прозрачность вне основного слоя и большие пустые области. Автоматическая проверка не доказывает правильность лица или швов.
- Уменьшение nearest-neighbor не исправляет смещение частей моделью. Проверяйте результат со всех сторон в 3D.
- История живёт в памяти вкладки. Сохраняйте PNG перед закрытием.
- Тесты подменяют ответ Google и не расходуют квоту. Реальный результат нужно проверить с вашим ключом.

Документация: https://ai.google.dev/gemini-api/docs/generate-content/image-generation
