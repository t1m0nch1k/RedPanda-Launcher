# RedPanda Launcher website

The website is a Next.js application for the RedPanda Launcher project.

## Development

```bash
npm install
npm run dev
```

Open <http://localhost:3000> to view the site.

## Checks

```bash
npm run lint
npm run build
```

The production download links point to the official GitHub release assets.
Release checksums are published beside the installer as `.sha256` assets.
